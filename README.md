NearPing — Hyper-Local Lost & Found & Urgent Help Platform

NearPing is a hyper-local community platform that helps people quickly connect with nearby users for lost & found items, urgent help, and local needs.

Users can create a location-based ping with details about what they lost, found, or need. People nearby can discover these pings and respond, making it easier to solve local problems quickly.

🔥 Main Features
📍 Location-based posts/pings
🔎 Lost & Found items
🆘 Urgent help requests
🗺️ Nearby pings on map
💬 User-to-user communication
🔔 Real-time notifications
👤 User profiles
📸 Image upload
🔐 Authentication
💻 Tech Stack

Frontend: React.js
Backend: Node.js + Express.js
Database: MongoDB
Other: REST API, Git/GitHub, Maps/Location services
